# Industry benchmark rubric

Evaluation aid, **not authorized scope**. Named incumbents are comparison
anchors, not a claim that OpenAd must match any one of them. Identity fence and
ROADMAP out-of-scope stay `record-only` / `blocked-by-invariant` unless both
skills independently tag `required-for-professional-use` (and fence items still
cannot be overridden that way).

| Phase | Industry problem | Norm to probe | OpenAd surface |
| --- | --- | --- | --- |
| Discovery | Opaque IO decks; spoofed domains | Size, domain, from-price, window before a login wall (GAM / BuySellAds) | Discover, SlotCard, slot page |
| Price | Surprise fees; delayed Net-60 | All-in or itemized take rate before pay (Uniswap / DICE-style clarity) | Buy dialog quote + `fee` |
| Creative | JS malware on publisher pages | Static verified assets; no advertiser HTML/JS (Brave Ads / Ethical Ads) | Campaigns register + serve |
| Approval | Trafficker bottlenecks vs open RTB | Named approval / allowlist / WAIVED (GAM creative review) | Supply inbox, request approval |
| Buy | Escrow, bids, keepers | One tx, first buy wins Dutch (not English auction) | `buy_with_permit` |
| Settlement | Agency rebate opacity | Same-tx split to publisher + treasury `fee_bps` | Earnings, Marketplace empty |
| Brand safety | Cookie / IDFA collapse | Lease of a slot NFT + verified domain, not surveillance | Domain verification, blocked creatives |
| Wallet | Seed-phrase anxiety | Rainbow / Coinbase connect, SIWE, permit (not custodial dashboard) | Connect, SIWE, WalletRail |
| Delivery | Impression fraud | Honest serve counts from indexer, not on-chain clicks | Campaigns delivery |
| Embed | Tag soup / GPT wrappers | Copy-paste `<open-ad>` talking only to serve | Embed demo :5174 |
