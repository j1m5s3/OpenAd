# Glossary

Use these terms exactly, in code identifiers, docs, UI copy, and commit messages. Do not
introduce synonyms (e.g. do not say "listing" when you mean "terms", or "space" when you mean
"slot").

| Term                     | Meaning                                                                                                                                                                                                                                                                                                                           |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Publisher**            | The owner of a slot NFT. Provides the ad space (a website, newsletter, etc.). Receives sale proceeds. Identified by the wallet address that holds the slot.                                                                                                                                                                       |
| **Advertiser**           | The party that registers creatives, buys periods (LEASE), and/or funds campaigns (CPC). Identified by a wallet address.                                                                                                                                                                                                           |
| **Platform**             | OpenAd itself: the contract owner (fee/treasury/moderator settings) and operator of the off-chain services (indexer, API, serving edge).                                                                                                                                                                                          |
| **Moderator**            | An address authorised by the platform to globally revoke a creative (emergency takedown).                                                                                                                                                                                                                                         |
| **Slot**                 | One unit of ad space, represented as one ERC-721 token in `AdSlot`. Has an immutable `SlotSpec` (dimensions, kind, domain). Persistent; never "sold" by the protocol, only leased.                                                                                                                                                |
| **SlotSpec**             | Immutable description of a slot: `width`, `height` (px), `kind` (placement type), `domain` (host the slot lives on).                                                                                                                                                                                                              |
| **Calendar**             | Per-slot time grid set by the publisher: `period_seconds` and `first_period_start`. Defines fixed, non-overlapping **periods**. Has a `version`; replacing the calendar bumps the version.                                                                                                                                        |
| **Period**               | One window of the calendar, identified by `period_index` (0-based from `first_period_start`). In LEASE mode, the unit that is auctioned and leased. `[start, end)` with `end = start + period_seconds`.                                                                                                                           |
| **Lease**                | The right, held by an advertiser, to have their creative served on a slot for one period. Written only by the `Marketplace`. Expires automatically at period end.                                                                                                                                                                 |
| **Terms**                | Per-slot sale parameters set by the publisher in `Marketplace`: `start_price`, `floor_price`, `lead_seconds`, `sale_end`, `approval_mode`, `paused`, and (ADR-0014) `sale_mode`, `floor_cpc`.                                                                                                                                     |
| **Sale mode**            | Per-slot terms flag. `LEASE`: Dutch/`buy` as in v1. `CPC`: campaigns compete at serve time; `buy` reverts. One mode at a time.                                                                                                                                                                                                    |
| **Auction**              | The Dutch price schedule for one period in **LEASE** mode: opens `lead_seconds` before the period starts at `start_price`, decays linearly to `floor_price` at period start. First `buy` wins. Not CPC matching.                                                                                                                  |
| **Buy**                  | The single LEASE-mode transaction that pays USDC and receives a lease. There are no bids. Not used in CPC mode.                                                                                                                                                                                                                   |
| **Creative**             | An advertiser-registered ad unit in `CreativeRegistry`. Kind `MEDIA` (URL + content hash + MIME + dimensions + click URL) or `NFT_REF` (chain, contract, token id). Immutable after registration except for revocation.                                                                                                           |
| **Approval**             | A publisher's per-creative decision (`APPROVED`/`REJECTED`/`REVOKED`), scoped to the publisher's address and reusable across all their slots.                                                                                                                                                                                     |
| **Allowlist**            | A publisher's blanket approval of an advertiser address; all of that advertiser's active creatives count as approved for that publisher.                                                                                                                                                                                          |
| **Campaign**             | An advertiser-funded CPC bid on one slot: creative, max CPC, remaining USDC in the campaign vault. Competes at serve time. Does not write a lease.                                                                                                                                                                                |
| **Floor CPC**            | Publisher minimum charge per payable click on a CPC slot (`Terms.floor_cpc`).                                                                                                                                                                                                                                                     |
| **Max CPC**              | Advertiser ceiling per payable click on a campaign. Actual charge is GSP, never above this, never below floor CPC.                                                                                                                                                                                                                |
| **Campaign vault**       | `CampaignVault`: holds campaign USDC until `settle_batch` or `finalize_close`. Not `Marketplace`.                                                                                                                                                                                                                                 |
| **Settler**              | Platform address allowed to `settle_batch` on the campaign vault. Cannot write leases or open campaigns. HTTP `api/` and `web/` do not hold this key.                                                                                                                                                                             |
| **Payable click**        | A click that passed token + IVT checks and may be included in `settle_batch`. House-ad clicks are never payable.                                                                                                                                                                                                                  |
| **Approval mode**        | Per-slot terms flag. `REQUIRED`: a buy or CPC `open_campaign`/serve needs an approved (or allowlisted) creative. `WAIVED`: needs only an active, non-blocked creative. LEASE records the mode on the purchase.                                                                                                                    |
| **Blocked**              | A creative is blocked for a publisher if that publisher rejected/revoked it, or a moderator revoked it globally. Blocked creatives are never served, even under `WAIVED`.                                                                                                                                                         |
| **Fee**                  | `fee_bps` (basis points, max 1000 = 10%) of each LEASE `buy` and each CPC `settle_batch`, sent to the platform `treasury` in the same transaction.                                                                                                                                                                                |
| **House ad**             | The publisher's own fallback creative, configured off-chain, served whenever no serveable lease or CPC campaign exists.                                                                                                                                                                                                           |
| **Listing**              | A publisher-provided audience description (a one-line summary, a longer audience description) and up to 3 categories for a **slot**, shown to advertisers on Discover and the slot page. Self-described, not verified — labelled "Publisher-provided". It is not the **slot** itself, unrelated to **Terms**, and never on-chain. |
| **Serve**                | The read-only act of returning the current creative for a slot to a page. Served from the indexer-derived database and verified media cache; **never** reads the chain in the request path.                                                                                                                                       |
| **Embed**                | The `<open-ad>` web component a publisher places on a page. Talks only to the serve endpoint.                                                                                                                                                                                                                                     |
| **Indexer**              | The off-chain worker that turns contract events into database rows. The database is a derived cache; the chain is the source of truth.                                                                                                                                                                                            |
| **Deployments artifact** | `contracts/deployments/<chainId>.json`: addresses + ABIs + start blocks for one chain. The only hand-off between contracts and the off-chain packages.                                                                                                                                                                            |
| **Verified domain**      | Off-chain flag: the publisher proved control of `SlotSpec.domain` (meta tag; DNS TXT is ROADMAP 7.16). Shown as a badge; not enforced on-chain.                                                                                                                                                                                   |

## Units and identifiers

- **Money**: USDC base units (6 decimals). `1_000_000 == 1 USDC`. Never floats.
- **Time**: Unix seconds (`uint64` on-chain). UI converts to local time.
- **Dimensions**: CSS pixels, `uint16`.
- **Ids**: `slot_id` (ERC-721 token id, starts at 0), `creative_id` (starts at 1; `0` means "none"), `campaign_id` (starts at 1; `0` means "none"), `period_index` (0-based), `calendar version` (starts at 1; `0` means "no calendar").
- **Chain ids**: 31337 Anvil, 84532 Base Sepolia, 8453 Base.
