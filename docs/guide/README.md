# Welcome to OpenAd

OpenAd is a **non-custodial** advertising marketplace. You connect a wallet. The
app never holds keys that can move your USDC or write a **lease**.

**Publishers** mint ad **slots** as NFTs. A slot is permanent space (a site, a
newsletter, a physical panel). You do not sell the slot. You lease **periods**
on it, or you run **CPC** **campaigns** against it.

**Advertisers** register **creatives**, get publisher **approval** when required,
then either **buy** a period (Lease / Dutch) in one USDC transaction, or fund a
CPC campaign that competes at serve time.

Everything you sign happens in your wallet. Serving never reads the chain and
never proxies your media files — the **embed** asks the serve API for the
current creative.

## Choose a path

- [Publisher](publisher/README.md) — mint a slot, set a calendar and terms, approve creatives, place the embed.
- [Advertiser](advertiser/README.md) — register a creative, get approval, buy a period or fund a campaign.

New to the vocabulary? Start with [Concepts](marketplace/concepts.md).
