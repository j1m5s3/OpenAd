# Advertiser

You register **creatives**, request **approval** when the **publisher** requires
it, then either **buy** a **period** (Lease) or fund a CPC **campaign**.

OpenAd never hosts your image bytes. The file is hashed in the browser; you
publish the bytes at a URL you control.

HTML/JS creatives are out of scope — raster images only.

## Sequence

1. [Register a creative](creatives.md)
2. [Request approval](approvals.md) if the slot’s **approval mode** is required
3. [Buy a period](buy-a-period.md) on Lease slots, or [open a CPC campaign](cpc-campaigns.md)
4. Watch [delivery](delivery.md)
