# Earnings

Supply shows USDC already credited to you.

- **Lease** — the advertiser **buy** pays you in that transaction (minus the
  **fee** to treasury).
- **CPC** — the **settler** batches **payable clicks**; each settle sends you
  proceeds minus fee.

**Pricing suggestion** is an off-chain hint for Lease start/floor prices. It
does not write **terms** for you.
