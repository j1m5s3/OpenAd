# UX walkthrough

Extra coverage for `.cursor/skills/sandbox-ux-critique/`. Wear `pub-3` then
`adv-6`. Same stack protocol as [`README.md`](README.md).

## P0 — Setup

Stack once, pause sim, connect `?devwallet=pub-3`.

## P1 — Information architecture

Discover / Supply / Campaigns labels vs glossary. Search placement. Featured vs
All. Wallet rail vs Connect. Would an ads-ops person and a wallet-native user
both find the next action?

## P2 — Empty, error, loading

Disconnected Supply/Campaigns. API down copy. No slots indexed. Slot not found.
Buy when not sellable. SIWE failure banner (must not be muted-only).

## P3 — Forms and time

Unix timestamps, numeric kind / approval mode / NFT standard. Sale mode and
floor CPC named in copy (not raw `sale_mode`). Human dates, select controls,
USDC fields. Transaction pending vs indexer-confirmed.

## P4 — Buy dialog and permit

Focus trap, Escape/Close, fee itemization, live quote refresh, creative picker,
disabled states, remainder CTA. CPC Open campaign / top-up permit dialogs.
Compare Rainbow/Uniswap permit UX.

## P5 — Mobile

375-wide: nav overflow, search, wallet rail (`lg:block` today), period table,
forms. Touch targets.

## P6 — Accessibility

Labels, heading order, contrast on canvas/accent, dialog semantics, keyboard
Connect and Buy.

## P7 — Embed demo

`:5174` house vs lease creative, error fallback, copy-paste snippet discoverability
from Supply.
